# Wanted: Maintainer for this stack

This stack extension is open for contribution. See the root [CONTRIBUTING.md](../CONTRIBUTING.md) for the quality bar and submission process.

The first contributor whose extension passes review becomes the maintainer for this stack. The bar is the [dotnet](../dotnet) folder — match its structure, depth, and grounding in real production work.

If you're interested, open an [extension request](../.github/ISSUE_TEMPLATE/extension_request.md) before starting work so we can confirm the stack is still open and answer any questions about scope.
