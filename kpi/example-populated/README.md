# Example Populated Files

Sample populated JSON files demonstrating the canonical schema. Drawn from anonymized real-world session work to provide adopters with concrete examples beyond schema definitions alone.

`example-session-01.json` shows a clean Polish session that shipped without drift.

`example-drift-moments.json` shows four drift incidents with different categories (scope_misread, pattern_divergence, over_engineering, premature_completion) demonstrating the variety of drift the framework captures. These are anonymized derivations from real session work — the patterns are real even though identifying details have been generalized.

These files are illustrative. Real adopting projects MUST replace `"project": "ExampleProject"` with their actual project identifier.
